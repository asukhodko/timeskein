# Architecture Decision Records (ADR)

This directory contains Architecture Decision Records for the Timeskein project.

## What is an ADR?

An ADR documents a significant architectural decision made during the project. It captures the context, decision, and consequences.

## Status Legend

- **Accepted** - Decision is final and implemented
- **Draft** - Under discussion
- **Superseded** - Replaced by a newer ADR
