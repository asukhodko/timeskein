# User Story: Захват текущего контекста (Level 2)

## Статус

## Название

**Захват текущего контекста** (Context Capture)

## Короткое описание

Пользователь может **по явной команде** захватить текущий контекст (активное окно, URL вкладки) и использовать его для создания или привязки Work Item.

**Важно:** эта функция требует наличия источников событий (SourceNode) и работает **только по явному действию пользователя**, а не в фоновом режиме.

## Контекст и ценность

Эта user story расширяет базовую функциональность Manual-first инвентаря (Level 0), добавляя возможность:

- Автоматически извлекать refs из текущего контекста (URL, заголовок окна, ключи тикетов)
- Предлагать существующие Work Items по совпадению refs
- Обновлять `last_seen` при посещении ранее привязанных refs

**Ценность:** снижение трения при работе с реестром без потери контроля пользователя.

## User Story

**Как** пользователь, который ведёт несколько параллельных задач,  
**я хочу** по команде захватить текущий контекст (окно/вкладку) и связать его с Work Item,  
**чтобы** быстрее создавать записи и автоматически обновлять `last_seen` при возврате к задаче.

## Зависимости

Для реализации этой функции требуется:

1. **RFC: Event Ingest + SourceNode + Pairing** — механизм подключения источников событий
2. **Connector/Extension** — источник, предоставляющий текущий контекст:
   - Browser extension для URL/title
   - OS integration для активного окна
3. **Ref Extractor** — модуль извлечения refs из контекста

## Acceptance Criteria (критерии приёмки)

### 1) Команда "Захватить текущий контекст"

- Пользователь вызывает команду (hotkey/палитра).
- Система запрашивает текущий контекст от подключённого SourceNode.
- Система показывает извлечённые refs (URL, ключи тикетов, домен).
- Пользователь выбирает:
  - Создать новый Work Item с этими refs, или
  - Привязать refs к существующему Work Item.

### 2) Подсказки по сильным refs

- Если среди извлечённых refs есть "сильный" (issue_key, конкретный URL), и в базе есть Work Item с таким ref:
  - Система предлагает: "Похоже на [Work Item title]. Открыть?"
- Пользователь может принять предложение или проигнорировать.

### 3) Автоматическое обновление last_seen (опционально)

- Если включено: при посещении URL/контекста, который уже привязан к Work Item, система обновляет `last_seen`.
- Обновление происходит **только для явно привязанных refs**.
- Это поведение можно отключить в настройках.

### 4) Работа с SourceNode

- Функция работает только при наличии одобренного SourceNode.
- Если SourceNode не подключён, команда "Захватить контекст" показывает сообщение о необходимости подключения источника.
- Данные имеют provenance (источник, время, применённые политики).

## Отличия от Level 0 (Manual-first)

| Аспект | Level 0 | Level 2 (эта story) |
|--------|---------|---------------------|
| Создание Work Item | Вручную вводим title и refs | По команде из текущего контекста |
| Refs | Paste/ручной ввод | Авто-извлечение + ручное |
| `last_seen` | Обновляется touch/edit/open | + авто-обновление по refs |
| Источники | Не требуются | Требуется SourceNode |

## Примеры сценариев (Gherkin)

### Сценарий 1: Создать Work Item из текущего контекста

- **Given** пользователь открыл вкладку с тикетом `ABC-123`
- **And** browser extension подключён как SourceNode
- **When** пользователь нажимает "Захватить текущий контекст"
- **Then** система показывает извлечённые refs: URL тикета, ключ `ABC-123`
- **And** предлагает создать Work Item с title из заголовка вкладки
- **When** пользователь подтверждает
- **Then** создаётся Work Item с привязанными refs

### Сценарий 2: Подсказка существующего Work Item

- **Given** существует Work Item с ref `ABC-123`
- **And** пользователь открыл вкладку с тикетом `ABC-123`
- **When** пользователь нажимает "Захватить текущий контекст"
- **Then** система показывает: "Похоже на [title Work Item]. Открыть?"
- **When** пользователь выбирает "Открыть"
- **Then** открывается карточка существующего Work Item

### Сценарий 3: Нет подключённого SourceNode

- **Given** нет одобренных SourceNode
- **When** пользователь нажимает "Захватить текущий контекст"
- **Then** система показывает: "Для захвата контекста подключите источник данных"
- **And** предлагает перейти в настройки источников

## Out of Scope (для этой юзерстори)

- Фоновое наблюдение (always-on collectors) — это Level 3
- Автоматическое создание Work Items без подтверждения пользователя
- Episodes и Threads
- Семантический поиск по содержимому

## Миграционный путь от Level 0

При появлении этой функции:
- Существующие Work Items и refs остаются неизменными
- Новые refs получают provenance от SourceNode
- `state` и `note` остаются источником истины пользователя (автоматика не переписывает)
- Пользователь может отключить авто-обновление `last_seen`
