## 1. Обзор

Этот документ описывает UI/UX для Evidence-Mode — строго opt-in функции Level 3 для захвата screen evidence.

**Ключевые принципы UI:**
- **Opt-in emphasis:** Все UI-потоки подчёркивают, что Evidence-Mode — опциональная функция
- **Privacy-first:** Индикаторы приватности всегда видны
- **User control:** Пользователь имеет полный контроль над захватом и хранением
- **Cards = UI view:** Timeline Cards — это UI-представление, Episodes — доменная модель

### 2.3. Enable/Disable Toggle

**При включении:**
1. Показать информационный диалог о том, что будет захватываться
2. Запросить системное разрешение screen_capture (если не предоставлено)
3. Показать выбор provider (local по умолчанию)
4. Активировать захват

**При отключении:**
1. Остановить захват
2. Спросить: "Удалить существующие evidence artifacts?" (опционально)

**Важно:** Cards = UI view model, Episodes = domain model. Timeline Cards — это derived представление для отображения, не новая доменная сущность.

### 4.3. Timeline Card Components

| Компонент | Описание |
|-----------|----------|
| Time range | Временной диапазон эпизода |
| Summary | Краткое описание активности (генерируется provider) |
| Refs | Извлечённые ссылки (URL, файлы, тикеты) |
| Marks | Метки (включая Distraction Mark) |
| Preview button | Кнопка для просмотра артефакта (если не purged) |
| Actions menu | Меню действий (Purge, Link to Work Item, etc.) |

**Важно:** Distraction Mark — это классификация для самоанализа, НЕ механизм исключения данных.

## 5. Controls

### 5.1. Enable/Disable

**Расположение:** Settings → Evidence-Mode

**UI:** Toggle switch с информационным текстом

### 5.2. Pause/Resume

**Расположение:**
- Tray menu → Pause/Resume
- Settings → Evidence-Mode → Pause/Resume button
- Keyboard shortcut (configurable)

**Поведение:**
- Pause: немедленно останавливает захват, сохраняет настройки
- Resume: возобновляет захват с теми же настройками

### 5.3. Purge

**Расположение:**
- Settings → Evidence-Mode → Purge All Evidence
- Timeline Card → Actions → Purge this period
- Tray menu → Purge Evidence...

## 9. Opt-in Emphasis

### 9.1. Принципы

Все UI-потоки должны подчёркивать opt-in природу Evidence-Mode:

1. **Явное включение:** Evidence-Mode выключен по умолчанию
2. **Информированное согласие:** При включении показывается информация о том, что будет захватываться
3. **Постоянная видимость:** Статус Evidence-Mode всегда виден (tray indicator)
4. **Лёгкое отключение:** Pause/Disable доступны в один клик

### 9.2. First-time Enable Flow

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  Enable Evidence-Mode                                                [X]   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │

│                                                                             │
```

## 10. Accessibility

### 10.1. Keyboard Navigation

| Действие | Shortcut |
|----------|----------|
| Pause/Resume Evidence-Mode | Configurable (e.g., Ctrl+Shift+E) |
| Open Timeline | Configurable |
| Open Evidence Settings | Configurable |

### 10.2. Screen Reader Support

- Все индикаторы статуса имеют текстовые описания
- Timeline Cards имеют aria-labels с summary
- Диалоги имеют правильную структуру для screen readers

### 10.3. Color Contrast

- Все индикаторы статуса имеют достаточный контраст
- Не полагаемся только на цвет для передачи информации
